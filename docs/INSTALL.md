# Встановлення і робота з системою

Найпростіший спосіб запуску на будь-якій системі — команда `bash start.sh`. Скрипт перевіряє інструменти, встановлює бібліотеки Python, збирає ядро, проганяє тести, формує звіт і запускає панель на http://127.0.0.1:8080.

## macOS (Intel і Apple Silicon)

Homebrew і CMake не потрібні.

```bash
xcode-select --install                     # компілятор і Python від Apple (якщо ще не встановлені)
python3 -m pip install --user numpy pybind11
cd ~/Downloads/pao-system
bash start.sh
```

Звіт і акти відкриваються командами `open out/report.html` та `open out/acts`.

## Windows (через WSL)

1. У PowerShell від імені адміністратора виконайте `wsl --install` і перезавантажте комп'ютер.
2. Відкрийте застосунок **Ubuntu** і встановіть інструменти:
   ```bash
   sudo apt update && sudo apt install -y g++ cmake make python3-pip python3-numpy python3-pybind11 unzip
   ```
3. Скопіюйте й розпакуйте архів (`ІМ'Я` — ім'я користувача Windows):
   ```bash
   cp /mnt/c/Users/ІМ\'Я/Downloads/pao-system.zip ~ && cd ~ && unzip -o pao-system.zip && cd pao-system
   bash start.sh
   ```
4. Відкрийте http://127.0.0.1:8080 у браузері Windows. Звіт відкривається командою `explorer.exe out/report.html`.

## Linux

```bash
sudo apt install -y g++ cmake python3-pip python3-numpy python3-pybind11
bash start.sh
```

## Docker

```bash
docker build -t pao . && docker run -p 8080:8080 pao
```

## iPhone / iPad

Локально на iOS систему не зібрати, тож використовуйте GitHub Codespaces у Safari:

1. Завантажте `pao-system.zip` у новий репозиторій на GitHub.
2. Натисніть **Code → Codespaces → Create codespace**.
3. У терміналі виконайте `unzip pao-system.zip && cd pao-system && bash start.sh`.
4. На вкладці **PORTS** відкрийте порт 8080.

## Робота з панеллю

| Елемент | Що робить |
| --- | --- |
| Плитки вгорі | Кількість суб'єктів на кожному рівні нагляду і в терміновій процедурі |
| Реєстр | Суб'єкти, впорядковані за індексом, із поясненням причин рівня |
| +6 год / +24 год / +3 дні | Просування часу системи; ядро перевіряє строки звітування |
| Зареєструвати інцидент | Надсилає подію в ядро; у потоці рішень з'являються термінові процедури для пов'язаних суб'єктів |
| Проєкти актів | Затвердження або відхилення; акти з позначкою «перевірка людиною» потребують ПІБ посадової особи |
| Змоделювати | 2 млн симуляцій каскадних атак на поточних даних |

## Демонстраційний сценарій (5 хвилин)

1. Покажіть реєстр і поясніть, що індекс складається з чотирьох складових (див. [METHODOLOGY.md](METHODOLOGY.md)).
2. Зареєструйте інцидент у «Термінал «Гавань-Контейнер»» з постачальником «ТОС «ТерміналСофт»» і позначкою «вплив на хаб». У потоці рішень з'являться термінові процедури, зокрема для «Дельта-Флот» з іншого хабу, бо в нього той самий постачальник.
3. Двічі натисніть «+24 год», не подаючи звітів. Ядро зафіксує порушення ст. 23 NIS2 і підвищить рівень.
4. Спробуйте затвердити акт тимчасових заходів без ПІБ: система відмовить. Введіть ПІБ і затвердьте.
5. Натисніть «Змоделювати» і покажіть системні точки відмови.
6. Відкрийте `out/report.html`, розділ «Калібрування»: результати аудитів показують, що загроза слабко передбачає порушення.

## Типові проблеми

| Симптом | Рішення |
| --- | --- |
| `Не знайдено: c++` | macOS: `xcode-select --install`; Ubuntu: `sudo apt install g++` |
| Не встановлюється numpy або pybind11 | `python3 -m pip install --user --break-system-packages numpy pybind11` |
| Порт 8080 зайнятий (на Mac його може займати AirPlay) | `PORT=9000 bash start.sh`, потім відкрийте http://127.0.0.1:9000 |
| Потрібно лише запустити панель без перезбирання | `PYTHONPATH=python python3 -m pao serve` |
